# Security Policy

## Supported Versions

Only the latest version is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately by contacting the project maintainers. Do not disclose vulnerabilities publicly until they have been reviewed and addressed.

We will review your report and provide an update as soon as possible.
